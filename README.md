# צומחים – אתר

אתר React + Tailwind CSS 4, בנוי עם Vite. כולל:
מסך מסחר חי בראש העמוד (נרות, ממוצעים 10/21 ו-ווליום) שמתקדם עם הגלילה, סימולטור ריבית דריבית, מסלול 10 המפגשים, מחיר, עלינו, שאלות נפוצות,
טופס הרשמה שנשלח אליכם בוואטסאפ, תפריט נגישות, ודפי תקנון, פרטיות והצהרת נגישות.

## הרצה מקומית

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # תיקיית dist מוכנה להעלאה
```

## העלאה לאוויר (מומלץ: Vercel, חינם)

1. מעלים את התיקייה ל-GitHub.
2. ב-vercel.com → Add New Project → בוחרים את הריפו. Vercel מזהה Vite לבד.
4. Settings → Domains: מחברים דומיין (למשל tzomchim.co.il).
5. אם הדומיין שונה מ-`www.tzomchim.co.il`, מעדכנים אותו ב-`index.html`, `public/robots.txt`, `public/sitemap.xml` ו-`src/data.js`.

## איך עובדת ההרשמה

הטופס לא צריך שרת, API או מפתחות. אחרי שממלאים ולוחצים "שליחת ההרשמה בוואטסאפ", נפתח וואטסאפ אצל הנרשם עם כל הפרטים כבר כתובים,
ממוען ליאיר (`BRAND.phones[0]` ב-`src/data.js`). הנרשם רק לוחץ שליחה. אם הוואטסאפ לא נפתח, מוצג כפתור לפתיחה ידנית ומספר טלפון.

## לפני שעולים לאוויר

- אחרי פתיחת תיק עוסק: למלא את `businessId` (וכתובת, אם רוצים) ב-`src/data.js`. כל עוד השדות ריקים הם פשוט לא מוצגים.
- גיל היעד (16–18) מוגדר במקום אחד: `BRAND.ages` ב-`src/data.js` (וגם בתיאור ב-`index.html`).
- המסמכים המשפטיים נכתבו לפי הדין בישראל, אבל הם לא תחליף לבדיקה של עורך דין.

## מבנה

```

public/               favicon, תמונת שיתוף, robots.txt, sitemap.xml, תוכנית הקורס PDF
src/data.js           כל הטקסטים, המחירים והפרטים העסקיים
src/components/       Hero + Market (מסך מסחר חי), Simulator, Path, Pricing, About, Register, Footer, A11y, Legal
```
